# sheetrs-formula

A lossless spreadsheet formula AST: the parser, the printer (Excel and `OpenFormula` notations), the
reference rewriting that row and column deletions need, the cell and range addresses, and the date
systems of `LibreOffice` Calc (`DateSystem`: 1899-12-30, 1900-01-01, 1904-01-01).

The API is experimental: names and shapes may change.
