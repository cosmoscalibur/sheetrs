# Localization

Everything that shows or reads a value depends on a locale in `LibreOffice`: the text of
booleans, the separators and symbols of numbers, the order and names of dates, the names of
functions and the separators of arguments of a formula as the user types it, the order of
sorting. The categories of the environment (`LC_NUMERIC`, `LC_TIME`, `LC_COLLATE` and the rest)
and the language that the document and the interface use can differ from one another.

Production uses `en_US`, `es_CO` and a mix of the categories, so a locale is an input of the
operations that depend on it and not a constant.
