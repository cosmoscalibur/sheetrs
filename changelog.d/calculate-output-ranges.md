### Changed

- A range outside the declared outputs is an error that says which outputs are declared when the program is a compiled one (`sheetc calculate` without `-o`, an executable's JSON answer, `Mode::Values`): the new typed `sheetrs_engine::Error::OutsideOutputs` lists them (issue #106). `ranges` is a selection among the declared outputs there; with none declared the outputs stay the formula cells.
- Where `calculate` writes the workbook (the embedded mode: `sheetc calculate -o OUT --json`, an embedded executable or module with `--output OUT --json`, and the `calculate` of `sheetrs edit`, Python and WebAssembly) a range outside the declared outputs, or a constant, is read from the workbook just written, in memory and with the machinery of `query`, in the order asked (`sheetrs_answer`, which every one of those paths calls). It is not calculated again: the inputs are in the workbook, a constant has its value and a formula the outputs left out has the result the template stored (declare it as an output to have it calculated). A text that is no range of the workbook is still an error. No compiler is needed for it, so a WebAssembly module built with `--embed-template` answers it too.
