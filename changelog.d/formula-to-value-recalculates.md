### Fixed

- A conversion of formulas to values after a deletion (rows, columns, sheets, names) converted the stale results the file cached (an ODS saved by the previous step had none and kept its formulas, so a plan in one pass and the same operations saved one at a time gave different workbooks). The results are now calculated again with the engine before they are converted, as an application that calculates as it goes shows them (the engine of `sheetrs-compiler`, which `sheetrs-edit` depends on), and the same holds for a workbook saved stale (an XLSX marked to recalculate when it is opened, an ODS with no cached results). When the engine cannot calculate the workbook, the conversion is refused with the reason and nothing is written. A plan whose last change is followed by a conversion no longer marks the output to be recalculated when it is opened.
