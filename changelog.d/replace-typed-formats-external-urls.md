### Changed

- `sheetrs edit --replace`: a cell in `General` that is typed a text LibreOffice reads as a percentage, a date, a time, a currency amount, a scientific number or a fraction takes the number format LibreOffice gives it (`0.00%`, `MM/DD/YY`, `YYYY-MM-DD`, `HH:MM:SS AM/PM`, `[HH]:MM:SS`, `# ?/?`...), and a boolean always takes the boolean format; the style of the cell stays. An XLSX gets a new cell format in `styles.xml`; an ODS gets the data style and a copy of the cell style (or of the default style of its row or column), and the value type of LibreOffice (`percentage`, `date`, `time`, `currency`). Tested in both formats against what `replaceAll` leaves (`typed_general`, `typed_formats`).
- Text typed as `1 1/2`, `25:00`, `(5)` and `($5)` is read as a number, as the input line of LibreOffice reads it; `$1e3` stays text.
- The formula of a cell that refers to another workbook shows the file as LibreOffice shows it (`'file:///folder/test.xlsx'#$Sheet1.B3`), resolved against the folder of the document (`Source::external_urls`, `reader::external_url`; `ExternalWorkbook::target` and `address`), in `sheetrs query` searches and `sheetrs edit` replacements, which write the reference back as the file writes it. The oracle of `minimal_test` writes the folder of the document as `<folder>` so it does not depend on where the repository is.
