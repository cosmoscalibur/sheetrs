### Changed

- `sheetrs-engine`: the array of an operator over a range (`Data!A1:A40000*1`) is the whole range, the cells beyond the sheet's data included as empty values, as in LibreOffice: `CORREL`, `SLOPE`, `MODE` and the binary search of `MATCH` see them. `MODE` takes the smallest of the values that repeat most (`MODE.SNGL` the first). `VLOOKUP` and `HLOOKUP` take their table as an array, answer the error among the keys that the search reaches, and `Err:502` for an index outside the table. `LARGE`/`SMALL` outside the set are `#VALUE!`, a `SERIESSUM` that overflows is `Err:502`, and `SERIESSUM` meets its coefficients by the cell of the formula where it is not given a range.
- `sheetrs-engine`: the counts of arguments LibreOffice takes now run: `ROWS()`, `COLUMNS()` and `ROWS(a, b…)` (extents added up), `IF(c)`, `IFS()`/`IFS(c)`, `CHOOSE(i)`, `INDEX(x)`, `TAKE(x)`/`DROP(x)`, `TEXTBEFORE(t)`/`TEXTAFTER(t)`/`TEXTSPLIT(t)`, `NETWORKDAYS` with four arguments, `SHEETS(a, b…)` and `NORM.S.INV` with more; `RANDARRAY` refuses a sixth argument. `IFS(FALSE, 1, TRUE)` is `#N/A` (a last condition with no value is never looked at).
- `sheetrs-compiler`, `sheetrs-formula`: an array written in a formula may leave elements out (`{}`, `{1,2,}`, `{1,;2,3}`: empty elements), an array inside an array is `Err:533`, and a boolean written in an array is the number 1 or 0. An ODS array with `#ref!` is `#REF!`.
- `sheetrs-compiler`: 2,100 more rows of the oracle (`scripts/residual_formulas.txt`) probed with LibreOffice 26.8; `scripts/probe_arity.py` keeps an override for the one function (`RANDARRAY`) whose count LibreOffice refuses with numbers but not with every kind of argument.
