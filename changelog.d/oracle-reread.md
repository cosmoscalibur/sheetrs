### Changed

- The oracles of the edits compare with what LibreOffice shows when the workbook it leaves after the edit is saved and opened again (re-read), in both formats and for every operation, not with its memory right after the edit (`CONTRIBUTING.md`, *Parity and fidelity*). `sheetrs-edit/tests/assets/write_to/oracle.json` holds `reread` (the default load, the expected values), `cache_differences` (where a hard recalculation of that file shows another value: none), and the memory of LibreOffice only as informational `in_memory_differences`; the scripts that make the expected workbooks of the edits (`gen_book_fixtures.py`, `gen_recalculation_fixtures.py`, `make_shapes_oracle.py`, `compare_structure_with_libreoffice.py`, the replace oracles) save and open the file again before they read it. `write_to` is also checked against writing values (`set_value`, the inputs of a calculation).
