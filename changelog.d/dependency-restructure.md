### Changed

- **Breaking:** the dependencies between the crates are restructured so that the compiler no longer depends on the editor: `sheetrs-edit` depends on `sheetrs-compiler`. The engine is no longer injected into the editor: `Calculator`, `Recalculator`, `Calculation`, `Calculated`, `CalculateError`, `Editor::set_calculator`, `Editor::set_recalculator`, `Error::NeedsRecalculation` and `sheetrs_compiler::memory::{calculator, recalculator}` are removed, and a conversion of formulas to values after a change that leaves results stale, like the `calculate` step, calls the engine itself.
- **Breaking:** the XLSX and ODS writers move from `sheetrs-edit` to `sheetrs-io`, behind the feature `write` (off by default: the crates that only read do not compile them): `sheetrs_io::write` (`WorkbookModifications`, `modify_workbook*`, `CellWrites`, `Constant`, `ValueScope`, `RowRange`, `ColumnRange`), with its own error `sheetrs_io::write::Error`, which `sheetrs_edit::Error::Write` wraps. `sheetrs_edit` re-exports `CellWrites`, `Constant`, `ValueScope`, `RowRange` and `ColumnRange`.
- **Breaking:** `fill_template`, `fill_template_with_answer`, `fill_template_to` and `fill_template_to_with_answer` move from `sheetrs-edit` to the new crate `sheetrs-answer`; they return `Written { cells }`. `sheetc`, the editor and the WebAssembly base module (`sheetrs-rt-wasm`, feature `template`) use it. `sheetrs_compiler::Error::Edit` is replaced by `Error::Answer`.
- `EntryFormat` moves to `sheetrs-io` and the calendar arithmetic of the engine to `sheetrs-formula::calendar` (both are re-exported where they were).

### Added

- `sheetrs edit` has the engine, so `sheetrs edit -i FILE --replace A --with B --formula-to-value S -o OUT` runs in one invocation and converts what the formulas give after the replacement. The executable grows from 6.2 MB to 9.8 MB (`dist`); a deletion without a conversion costs what it did (7.5 s and 13 MB on 2.4 M formulas), and a deletion followed by a conversion on that workbook takes 27 s and 1.6 GB, the engine's memory (`scripts/README.md`, Comparisons).
- `sheetrs-answer`, the crate that writes the answer of a program into the workbook it was made from. CI checks the kernel with and without the feature `write` (also for WebAssembly).
