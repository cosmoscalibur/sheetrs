### Added

- An edit can keep the results the file caches instead of calculating every formula again (issue #126): `Book::set_recalculate(false)` in Rust, `sheetrs edit --no-recalculate`, `recalculate=False` in `save`, `to_bytes` and `explain` of the Python `Book`, and `book.recalculate = false` in WebAssembly. The planner then adds no recalculation (neither the one that ends the run nor the one before a conversion), so the cells no operation touches keep the value the application that wrote the file computed, and the workbook is not marked to be recalculated when it is opened. A formula the operations rewrite is written without a cached result, a `calculate` operation runs as ever, and a workbook that says it is stale when the run starts is still calculated before a conversion reads it. The default is unchanged: the engine calculates every formula, because it has no dependency analysis of its own to tell the stale ones (documented in `sheetrs-edit/README.md`).
