### Added

- `sheetrs lint --format sarif` writes the findings as a SARIF 2.1.0 log (rules with their category and whether they are on by default, results with level, message, the cell as line and column of the table and its logical location), the format that GitHub code scanning, the editors and the CI read. It is written result by result and the tests validate it against the official schema. `--format json` stays: the document of the executable for an interface of your own, and `human` is still the default. The three are library functions (`sheetrs_linter::output::write_report`, with `human::write_human`, `json::write_json` and `sarif::write_sarif`) that the executable, the WebAssembly package (`lint_workbook`, `lint_workbook_json`, `lint_workbook_records`, `lint_workbook_sarif`) and the Python `Book.lint(config_path, format=...)` call.
