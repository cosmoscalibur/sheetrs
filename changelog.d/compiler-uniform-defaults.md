### Changed

- An executable that embeds its workbook (`--embed-template`) behaves as any compiled one, only with the workbook inside: inputs are declared or deduced, outputs are declared or deduced, the same as without `--embed-template`. Nothing declared gives the same default everywhere: the outputs are the cells that are calculated (the formulas, not the constants) as the rectangles that hold them, and the inputs the constants a path of the dependencies starts from. This changes the default of a program that is not embedded, whose outputs were every cell with a value or a formula.
- The workbook answer (`--output`) writes the inputs given and the outputs that are formulas into the template; the formulas outside the program keep the result the template stored (declare no outputs to refresh every formula). `Program::template` and `Program::template_rects` are gone; `Program::formula_cells` lists the formulas that are written. `--meta` says `deduced` or `declared` for the outputs (before, `all` or `formulas`).
