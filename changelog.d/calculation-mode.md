### Added

- The calculation mode of `LibreOffice` is the default of every run, and `calculate_all` emulates `calculateAll()` of its UNO API: `sheetrs edit --calculate-all`, `sheetc calculate --calculate-all`, `sheetc build --calculate-all`, `--calculate-all` of a compiled executable, `Book::with_calculate_all(true)` in Rust, `calculate_all=True` in Python (`save`, `to_bytes`, `explain`, `value_ranges`), `book.calculateAll = true` in WebAssembly (and `sheetrs_set_calculate_all` in the module of a compiled workbook), `calculate_all` in `sheetc.toml` and in the options of `compile`, `Spec::calculate_all` and `Overrides::calculate_all` in the libraries.
- `sheetc build --force-calculate-all` (the key `force_calculate_all`, `Spec::force_calculate_all`): the program stores no cached result for the formulas it keeps, so it calculates all of them in every run and is lighter. It applies to a build only, not to `calculate`.
- A compiled program carries the cached result of the formulas it keeps (`Program::cache`) and a run takes it for every formula that no changed input reaches (`Engine::take_cached`): only the cone of the inputs a request changes is calculated. `--info` lists `calculate_all` and `force_calculate_all` among the build options.

### Changed

- The default of a build is the load of `LibreOffice`: the constants it folds are the values the workbook stores (a formula that has a result and that no declared input reaches is folded as it), and the formulas it keeps carry the stored result; a formula with no result, a volatile one, and what reads them are calculated, and a workbook that reads cells at run time (`INDIRECT`, `OFFSET`) keeps no cache. With `calculate_all` the build first calculates the whole workbook and folds and stores those results. The inputs a calculation is given are its declared inputs when the workbook declares none, so what they do not reach is not calculated.
- `sheetrs edit` and the `Book` of every binding keep, by default, the results the file caches for the formulas the edit does not reach, and calculate what it reaches and what depends on it; a conversion of formulas to values converts the cached results of the cells nothing reaches and what the engine calculates for the rest, and with `calculate_all` what the formulas calculate. A conversion that needs the engine for a workbook that depends on what it cannot calculate (another workbook, a macro, an extension) is an error that names the cause. `sheetc calculate` with nothing given keeps the results the workbook caches too: `--calculate-all` calculates every formula.
- `sheetrs-edit/tests/assets/use_cache/` is `cached/`, and the oracle of the edits holds `reread_default` (what LibreOffice keeps and calculates when it opens, edits without `calculateAll()`, saves and opens the file again) next to `reread` (with `calculateAll()`).
