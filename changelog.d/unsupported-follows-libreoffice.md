### Changed

- A workbook that depends on what the engine cannot calculate (another workbook, a macro, an add-in or a function of `LibreOffice` the engine lacks) is run as `LibreOffice` runs it, with no option. A cell that no edit reaches keeps the result the file caches, and the report holds a warning of its kind (`EXTERNAL_FROM_CACHE`, `MACRO_FROM_CACHE`, `EXTENSION_FROM_CACHE`); what reads it is calculated from it. A cell the run calculates (an edit reaches it, or every formula is calculated) is what `LibreOffice` gives: an add-in that is not installed (`_xll.NAME`, `COM.SUN.STAR.SHEET.ADDIN.*`) is `#NAME?`; a macro, `WEBSERVICE`, `FILTERXML` and `DDE` have results only `LibreOffice` gives, so the run is an error that names the cause; a reference to another workbook keeps the stored value of the link. The behavior was observed in `LibreOffice` 26.8 (`sheetrs-compiler/docs/FIDELITY.md`, *What depends on what the engine cannot calculate*; `sheetrs-edit/tests/assets/from_cache/probe.py`). `sheetrs edit` no longer refuses a workbook with macros (`sheetc` does unless `--secure-mode`).

### Removed

- The options `external_from_cache`, `macro_from_cache` and `extension_from_cache`: the flags `--external-from-cache`, `--macro-from-cache` and `--extension-from-cache` of `sheetrs edit` and `sheetc`, the keys of `[global]` of `sheetrs.toml` and of `sheetc.toml`, `Book::with_from_cache`, `sheetrs_io::FromCache`, `Calculation::from_cache`, the keywords `external_from_cache`, `macro_from_cache` and `extension_from_cache` of the Python `Book` and `calculate`, and the options and properties `externalFromCache`, `macroFromCache` and `extensionFromCache` of the WebAssembly `Book`.
