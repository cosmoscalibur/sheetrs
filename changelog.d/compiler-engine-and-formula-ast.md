### Added

- `sheetrs-formula` crate: lossless formula AST with a single-pass parser, a canonical printer, reference rewriting for inserted/deleted rows and columns and renamed/deleted sheets, and an R1C1 form. Verified by parsing and round-tripping every formula of the repository's workbooks.
- `sheetrs-engine` crate: format-independent IR, function library and demand-driven evaluator with JSON in and JSON out (`sheetrs-rt`, the runtime stub of compiled executables).
- `sheetrs-compiler` crate and `sheetc` binary: compiles XLSX/ODS workbooks into standalone executables with hybrid compile/run-time evaluation, input/output pruning (inputs, outputs and metadata are declared in a `settings` sheet of the workbook, where `key` names the JSON field and `value` holds the range or literal, and are listed by `--meta`; `--outputs declared|named|any` chooses how much stays queryable; requests are `{"inputs", "ranges", "majorDimension"}` and range reads answer `valueRanges`, as in the Google Sheets batch read), constant folding, `sheetc verify` (recomputes a workbook's formulas and compares them with the values the file cached), validation of the declarations (formula inputs and empty outputs are errors, listed together; workbooks with macros are refused unless `--no-strict`), a `sheetc.toml` build configuration, a locale fixed at build time (`en` and `es` built in, others defined in the configuration), an in-house text collation checked against ICU, iterative calculation, and LibreOffice 26.8's behavior for both formats, with the settings and function names each format carries (`sheetrs-compiler/docs/FIDELITY.md`). It is the former `cosmoscalibur/xlslang` repository.
- `sheetrs-formula`: `calc_print::to_calc` prints a formula in LibreOffice's notation (`$Sheet.A1`, `TRUE()`, locale separators), which `FORMULATEXT` returns.
- `sheetrs-engine`: number and date format codes of `TEXT` follow LibreOffice, in the user's locale, checked against LibreOffice results in English and Spanish (`sheetrs-compiler/docs/FIDELITY.md`).
- `sheetrs-engine`: `UNIQUE`, `LET`, `DOLLAR`, `FORMULATEXT`/`ISFORMULA` (answered at build time) and LibreOffice's long-text wrapper; `LET` is resolved while lowering the formula. The locale has `currency_after`, `currency_parens`, `am` and `pm` for them.
